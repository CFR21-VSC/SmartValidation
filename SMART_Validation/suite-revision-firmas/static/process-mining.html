Definición del SOP (proceso ideal)

Comparación puramente determinística (sin IA): cada etapa mide el tiempo real transcurrido entre dos hitos del ciclo de firma, y se marca como desvío cuando supera el umbral que definís acá. Guardar crea una versión nueva — nunca se pisa una anterior, así que se puede iterar sin perder el historial.
