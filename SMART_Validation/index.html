★ Libro de Validación

Entregable maestro que compila todos los docs del proyecto en un único PDF tipo libro. Diseñado para ser presentado ante auditoría regulatoria (ANMAT, FDA, EMA) como evidencia única de la validación del sistema.

CONTENIDO DEL LIBRO:
  1. Portada: identificación del sistema + decisión global "SISTEMA VALIDADO"
  2. Prefacio: estructura del libro y propósito
  3. Índice maestro: tabla navegable (TOC) con todos los docs · click en cada código salta a la sección
  4. Registro maestro de firmas: consolidación de TODAS las firmas del ciclo con hash-ref criptográfico (21 CFR Part 11)
  5. Cascada documental: cada doc del paquete renderizado completo en orden canónico (HLRA → VP → URS → FRS → DS → RA → IRA → RRM → MTR → PIQ → IIQ → RIQ → POQ → IOQ → NCR → ROQ → PPQ → IPQ → RPQ → AEX → VSR)
  6. Contratapa: cierre formal del libro
Características técnicas:
  • Numeración GLOBAL consecutiva (Página X de Y)
  • Header en cada página con título del libro
  • TAB dividers entre secciones (tipo separador de libro)
  • Cada doc conserva sus firmas, decisiones y trazabilidad originales
  • Compilación determinística: se regenera idéntica cada vez desde los mismos documentos aprobados
Cómo se genera:
1. Al crear un proyecto nuevo desde Suite Proyectos, los docs base (HLRA + VP + URS + RA + IRA) se cargan automáticamente. Para sumar otros docs, usá Suite Evidencias → Importar docs al proyecto, o cargá la Demo DRP.
2. Suite Libro de Validación → ★ Generar Libro de Validación.
3. Confirmá la decisión global y el período del ciclo.
4. Se descarga el PDF compilado.
